This course provides an introduction to Machine Learning algorithms.
The topics covered will include basic concepts on information theory, classification vs regression problems, supervised vs unsupervised vs reinforcement learning, neural networks, and generative AI. 
The aim of the course is to provide strong foundations at both the mathematical and theoretical level, while providing practical exercises to work on real data.

The course is organized in four chapters, covering the topics listed below. 
All will be followed by a practical session and hands-on coding in `Python`, with Jupyter notebooks. 
No prior mathematical or programming experience is required to attend this course.

## Roadmap of the course

### Chapter 1. What is learning?

- Foundations of learning and information theory.
- Regression vs classification, continous vs categorical and logistic.
- Example of classification problem, the KNN: predict a cell's type by looking at similar cells.
- Example of regression problem, the fit: find the best model explaining gene expression vs stimulus.
- Unsupervised learning: k-means and PCA, find groups of cells without labels.
- Reinforcement learning: Q-learning, learn from rewards by trial and error.

### Chapter 2. Simple mathematical intuitions.

- Loss functions. Quantify accuracy / error of a prediction, and some examples.
- Derivatives. A recap on calculus, and modelling change.
- Gradient descent. Minimize a loss by following its derivative.

### Chapter 3. Artificial Neural Networks.

- Weights and biases. A layer of neurons as a matrix-vector multiplication.
- Activation functions. Model decision thresholds, and some examples.
- A neural network with TensorFlow and PyTorch: classify tumour vs normal cells.

### Chapter 4. Generative AI.

- Stochasticity and Markov processes: Markov chains and hidden Markov models.
- Memory and context: when the last step is not enough.
- The transformer technology: attention, pattern recognition with memory access.
- Modern applications: `AlphaFold` and `GPT` language models.
